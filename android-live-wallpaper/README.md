# Android 라이브 배경화면

웹앱과 같은 산호초 이미지와 생물을 사용하는 Android 네이티브 라이브 배경화면입니다.

## 사용

1. APK를 Android 휴대폰으로 옮겨 설치합니다.
2. `나의 산호초 바다` 앱을 엽니다.
3. `움직이는 배경화면으로 설정`을 누릅니다.
4. 미리보기에서 `배경화면 설정`을 누릅니다.

홈 화면의 빈 물을 누르면 거품이 올라옵니다. 물고기를 누르면 해당 물고기만 앞으로 빠르게 달아납니다. 속도와 물고기 수는 앱에서 조절할 수 있습니다.

## 빌드

JDK 17, Android SDK API 35, Gradle 8.9가 필요합니다.

```bash
./gradlew assembleDebug
```

생성 파일은 `app/build/outputs/apk/debug/app-debug.apk`입니다.

## iPhone 안내

iOS는 제3자 앱이 홈 화면 뒤에서 계속 실행되는 라이브 배경화면을 제공하지 않습니다. 앱 화면에서는 계속 움직이고 터치할 수 있지만, 시스템 배경화면은 잠금화면이 켜질 때 재생되는 Live Photo 방식으로만 구현할 수 있습니다.
